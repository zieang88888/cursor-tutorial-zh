# 07 模型与提供商

> 用哪个模型、怎么接自己的 API Key、怎么省钱——模型选对了，体验差一倍。

## Cursor 内置模型

- **入口**：Settings → Model / Chat 面板顶部模型切换
- **常见选择**：Claude 系列（长文本/代码强）、GPT 系列（通用稳）、Cursor Small/Fast（免费快速）
- **避坑**：模型名会随版本变化；显示"Slow"表示免费额度用尽在排队，可切小模型救急

## 免费额度与付费模型

- **免费版**：少量高级模型快速请求 + 无限慢速
- **Pro 版（$20/月）**：高级模型快速请求额度大幅提升
- **按量计费**：额度用完后可选择按 API 用量付费（Pay-as-you-go）
- **避坑**：长对话/大 Agent 任务烧额度很快，重度使用建议直接 Pro

## 接入自己的 API Key

- **操作路径**：Settings → Models → 打开 `Use own API key` / 添加自定义模型 → 填入 API Key 与模型名
- **支持**：Anthropic / OpenAI / 兼容 OpenAI 接口的第三方（DeepSeek、通义、智谱等）
- **优势**：自己付费、可用国产模型、规避 Cursor 额度限制
- **避坑**：自定义模型体验取决于各家 API 的稳定性；密钥仅存本地，别提交仓库

## 模型选择建议

| 场景 | 推荐 |
| --- | --- |
| 日常补全/小改动 | 默认模型 / Cursor Small |
| 长代码生成、架构设计 | Claude 最新版 / GPT 最新版 |
| 中文场景 | GPT/Claude 均可，国产模型中文更地道 |
| 省钱日常 | 慢速免费额度 + 自己 API Key 兜底 |

## 不同模型的行为差异

- **Claude 系**：代码质量高、长指令遵循好，适合 Agent 大任务
- **GPT 系**：通用性强、工具调用稳，适合对话与混合任务
- **小模型**：快而省，但复杂逻辑容易"偷懒"，只用于简单补全
- **避坑**：同一任务在不同模型结果差异大，重要任务固定用同一强模型，别换来换去

## 上下文与 Token 消耗

- **相关概念**：上下文窗口（一次能"记住"多少）、Token（计费单位）
- **省钱技巧**：
  - 新任务开新对话，别让上下文无限膨胀
  - 大文件别整文件 @，让 AI 只读需要的部分
  - 定期让 AI"总结当前进展"，压缩上下文
- **避坑**：上下文超限时 AI 会"忘事"，表现为答非所问——此时开新对话并补充关键信息

## 请求失败与重试

- **现象**：请求超时、模型无响应、Rate limit
- **对策**：先等 10-30 秒重试；检查网络代理；检查 API Key 余额；降级到小模型
- **避坑**：多次失败别反复重试同一个请求，先排查根因

## 一句话原则

> **模型是 Cursor 的"发动机"：日常用快的，关键用强的，特殊场景接自己的 Key。**
