# 03 Chat 对话模式

> 跟 AI"聊天改代码"：问问题、改文件、查代码库——`Ctrl+L` 打开的世界。

## 打开 Chat 面板

- **操作路径**：`Ctrl+L`（macOS `Cmd+L`）→ 底部输入框出现 → 输入问题/指令 → Enter
- **适用场景**：问代码逻辑、让 AI 改当前文件、解释报错
- **界面要素**：输入框（可 @ 引用文件）、对话历史、模型切换、Agent 模式开关

## @ 引用文件与代码库

- **操作路径**：输入框输入 `@` → 弹出候选 → 选择文件 / 文件夹 / 代码库索引 / Web 搜索
- **适用场景**：让 AI 参考指定文件、搜索整个项目、查找相关代码
- **能力**：
  - `@文件名`：引用单个文件
  - `@Codebase`：全项目语义检索（首次会建立索引）
  - `@Web`：联网搜索（需手动开启）
- **避坑**：不加 @ 时 AI 默认只看当前文件；问"整个项目"相关的问题务必 @Codebase

## 让 AI 修改当前文件

- **操作路径**：Chat 中描述需求 → AI 给出修改方案与代码 → 点"Apply"应用到文件
- **适用场景**：多步骤修改、需要解释的改动
- **避坑**：Apply 前看 Diff；AI 可能只改了一部分，用"还有哪里没改"追问

## 追问式对话

- **操作路径**：AI 回答后继续输入追问 → 对话上下文连续
- **适用场景**：逐步深入理解问题
- **示例**："为什么这样写？" → "换一种更简单的写法" → "边界情况怎么处理"
- **小技巧**：对话太长会变慢变贵，关键结论可让 AI"总结一下刚才的方案"

## 上传图片提问

- **操作路径**：Chat 输入框 → 粘贴截图 / 拖入图片 → 描述问题
- **适用场景**：UI 设计图转代码、报错截图分析、架构图讨论
- **避坑**：图片清晰度影响识别；截图别带无关信息

## 报错信息处理

- **操作路径**：复制报错文本 → Chat 里粘贴 → 附上相关代码/文件
- **适用场景**：编译错误、运行时报错、类型报错
- **高质量提问模板**："粘贴报错 + @相关文件 + 说明期望行为"，比只贴报错有效十倍

## 新对话 vs 继续对话

- **新对话**（`Ctrl+L` 后按 `Ctrl+N` 或点击 New Chat）：适合新问题，避免旧上下文干扰
- **继续对话**：适合同一问题的连续追问
- **避坑**：跨问题混在一个对话里，AI 容易"跑偏"，该开新对话就开新对话

## Chat 的定位

> **Chat 适合"理解和讨论"，Ctrl+K 适合"单点修改"，Composer/Agent 适合"多文件干活"**——三个入口各有分工，别用 Chat 硬干大活。
