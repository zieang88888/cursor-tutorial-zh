# 09 快捷键与效率技巧

> 常用快捷键一张表 + 让 AI 更好用的日常技巧——记住这页，效率翻倍。

## 核心快捷键速查表

| 快捷键 | 功能 |
| --- | --- |
| `Tab` | 接受 AI 补全 |
| `Ctrl+K` | 行内编辑（Inline Edit） |
| `Ctrl+L` | 打开 Chat |
| `Ctrl+I` | 打开 Composer / Agent |
| `Ctrl+N`（Chat 中） | 新建对话 |
| `Ctrl+Enter` | 提交消息 / 接受 AI 修改 |
| `Esc` | 取消 AI 修改 / 关闭面板 |
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+Shift+X` | 扩展面板 |
| `Ctrl+\`` | 终端 |
| `Alt+↑/↓` | 上移/下移代码行 |

> macOS 用户把 Ctrl 换成 Cmd 即可。完整列表见命令面板 → Keyboard Shortcuts。

## 让补全更聪明的技巧

- **写注释先行**：先写 `// 把用户按活跃度排序`，再写代码，AI 补全质量明显提升
- **小步提交**：文件别写太长，AI 上下文更聚焦
- **用规则约束**：全局规则写明偏好（见第 05 章）

## 让对话更高效的技巧

- **一次说清**：背景 + 目标 + 约束一次给全，别挤牙膏
- **给示例**：想要特定风格，贴一段"参考样例"
- **要求结构化输出**："用表格列出三个方案，对比优缺点"
- **善用 @**：需要参考什么就 @ 什么（文件/代码库/Web）

## 多光标与批量编辑

- **操作路径**：`Alt+Click` 添加光标 → 多行同时编辑 → 配合 Ctrl+K 批量改
- **适用场景**：批量改名、统一格式
- **避坑**：批量操作前先 `Ctrl+Z` 备份心理（改错可撤销）

## 会话管理技巧

- **任务分开**：每个功能一个 Composer，别全塞一个对话
- **定期总结**：长任务让 AI 阶段性总结，避免上下文爆掉
- **收藏常用提示词**：把常用指令存成 snippets/规则文件，随取随用

## 终端内的 AI（可选）

- Cursor 终端支持将报错一键发送给 AI 分析（右键 → 复制并询问 AI）
- **适用场景**：终端报错快速定位

## 效率自查清单

- [ ] 我有没有先用注释"预告"我要写的代码？
- [ ] 修改跨文件时，我是不是还在用 Ctrl+K 硬改？
- [ ] 我的项目有没有 .cursor/rules？
- [ ] 大任务我是不是开着 Agent 而不是 Chat？
- [ ] 提交前我有没有让 AI 生成规范的 commit message？

## 一句话原则

> **快捷键解决"怎么按"，技巧解决"怎么问"——工具和提问方式各占一半效率。**
