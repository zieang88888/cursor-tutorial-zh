# 01 安装与界面设置

> 从零开始：下载、注册、中文界面、界面布局——十分钟跑起来。

## 下载与安装

- **操作路径**：官网 https://cursor.com → Download → 选择 Windows/macOS/Linux 对应版本 → 安装包安装
- **适用场景**：所有新用户的第一步
- **避坑**：Windows 安装时建议选"仅为当前用户安装"；安装包约 200MB+，下载慢可换网络重试

## 注册与登录

- **操作路径**：启动 Cursor → Sign in → 支持 Google / GitHub / 邮箱注册
- **适用场景**：首次使用必须登录，免费版即可用
- **避坑**：登录失败常见原因是网络无法访问境外服务，需稳定代理；登录态失效后重新登录即可，本地配置不丢失

## 免费版与 Pro 版

- **免费版**：每月少量高级模型快速请求 + 无限次慢速请求，个人学习足够
- **Pro 版（$20/月）**：更多快速请求、优先模型队列，适合日常重度使用
- **避坑**：免费额度用完后模型会变"慢速"（排队），不是坏了；想省钱可切低配模型

## 中文界面设置

- **操作路径**：`Ctrl+Shift+P` → 输入 `Configure Display Language` → 选择 `简体中文` → 重启
- **适用场景**：不习惯英文界面的用户
- **避坑**：语言包需联网下载；若命令面板无该命令，先更新 Cursor 到最新版

## 界面布局速览

- **左侧活动栏**：资源管理器 / 搜索 / 源代码管理 / 调试 / 扩展
- **顶部 Tab 区**：文件标签 + 右侧"AI 功能入口"
- **AI 面板**：`Ctrl+L` 打开 Chat，`Ctrl+I` 打开 Composer/Agent——这是与 AI 交互的主战场
- **底部状态栏**：模型名称、请求额度状态、错误提示
- **避坑**：新版本界面布局可能微调，认准图标不认位置

## 主题与字体

- **操作路径**：`Ctrl+,`（设置）→ 搜索 `Color Theme` / `Font Size`
- **适用场景**：视力偏好、截图分享
- **小技巧**：推荐安装 JetBrains Mono 或 Fira Code 字体 + 开启连字（Ligatures），代码更易读

## 导入 VS Code 配置

- **操作路径**：设置 → 选择 `Import from VS Code` → 选择 .vscode 配置目录
- **适用场景**：从 VS Code 迁移过来的用户
- **效果**：快捷键、主题、扩展、settings.json 一键迁移
- **避坑**：部分 VS Code 扩展依赖 Node 运行时，装不上属于正常现象，不影响核心 AI 功能

## 首次启动推荐设置

- 开启：Auto Save（自动保存）、Editor: Format On Save（保存时格式化）
- 设置默认模型：Settings → Model → 按需求选择（见第 07 章）
- 关闭不必要遥测：Settings → Privacy 中按需关闭
- **小技巧**：把 `Cursor 教程` 第 09 章快捷键表打印一份贴在显示器旁，效率翻倍
