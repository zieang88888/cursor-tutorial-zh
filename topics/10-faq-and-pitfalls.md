# 10 常见问题与避坑

> 高频问题一张表查完：登录、网络、规则、Token、隐私——遇到问题先翻这篇。

## 登录与账号问题

| 问题 | 原因与对策 |
| --- | --- |
| 登录不上 / 转圈 | 网络访问境外服务不畅，检查代理；换节点重试 |
| 登录后掉线 | 登录态过期，重新登录即可，本地配置保留 |
| 提示账号受限 | 免费额度/风控，检查邮箱验证状态或联系官方支持 |

## 网络与代理问题

- **现象**：AI 请求超时、补全不出、模型列表加载失败
- **对策**：
  1. 检查代理是否开启、节点是否有效
  2. Cursor 设置里配置代理（Settings → 网络）
  3. 关闭系统代理直连测试（部分地区直连可用）
- **避坑**：代理不稳定时 AI 表现"时灵时不灵"，先解决网络再看别的

## 规则不生效

- **检查项**：
  - `.cursor/rules/` 路径是否正确（项目根目录）
  - 规则文件是否保存、文件名是否规范（.mdc）
  - 是否写了 `globs` 但文件不在匹配范围
  - 规则是否过长被截断（精简）
- **验证方法**：Chat 里问"当前项目有哪些规则"，AI 会告诉你它读到了什么

## Token / 额度消耗快

- **原因**：长对话、大文件 @、Agent 大任务、频繁重试
- **对策**：
  - 新任务开新对话
  - 别整文件 @，用 @Codebase 或点名关键函数
  - 大任务用强模型一次到位，别用小模型反复试错
  - 关注 Settings 里的用量统计，找到"烧钱大户"
- **避坑**：慢速（Slow）状态是额度耗尽在排队，不是故障

## 代码被 AI 改坏了

- **对策**：
  - 立刻 `Ctrl+Z` 撤销
  - 看 Diff 定位改动，逐块回滚
  - 用 git 历史恢复（养成频繁 commit 习惯）
- **预防**：重要改动前先 commit；让 AI"最小化改动"

## AI 答非所问 / 上下文丢失

- **原因**：对话过长、上下文超限、任务跨度过大
- **对策**：开新对话，把关键信息（背景/目标/约束）重新给一遍；大任务拆小
- **避坑**：别在同一个对话里塞多个无关任务

## 隐私与数据安全

- **默认行为**：对话与代码会发送给模型提供商处理
- **控制选项**：
  - Settings → Privacy：关闭代码发送/遥测（会牺牲部分功能）
  - 企业版：可配置数据不用于训练
  - 敏感项目：用自有 API Key + 私有部署模型，或改用本地模型
- **避坑**：不要把 API Key、密码写进对话或规则文件

## 更新与版本

- **更新方式**：应用内自动更新 / 官网下载最新版
- **避坑**：大版本更新后快捷键与界面可能变化，看 changelog 了解变更
- **小技巧**：遇到诡异 bug，先检查是不是最新版；旧版问题在更新后常自动消失

## 找不到的功能

- **对策**：`Ctrl+Shift+P` 搜功能名 → Settings 搜索 → 官方文档 https://docs.cursor.com/ 查
- **避坑**：很多"新功能"在设置里默认关闭，搜关键词就能找到

## 一句话原则

> **90% 的问题 = 网络 + 额度 + 上下文，剩下 10% 查官方文档——先查这三样，再问社区。**
